# Travelneeds by Ziza — Concept Demo

A responsive website and booking-system concept prepared as a sales sample for Travelneeds by Ziza.

## Live demo

Once GitHub Pages is enabled, the site will be available at:

`https://shukritobi.github.io/travelneeds-by-ziza/`

## What the demo includes

- Travel-deal landing page
- Responsive package cards and filters
- Package-enquiry modal
- Booking and sales dashboard preview
- MATTA Fair crew tracking concept
- Dynamic event countdown
- Structured lead form
- Mobile navigation and accessible interactions

## Important

This is a concept presentation. Package details, prices, customer names, testimonials and dashboard data are placeholders. Replace them with verified business information before production use.

## GitHub Pages deployment

A Pages workflow is included under `.github/workflows/pages.yml`.

In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions** if it is not selected automatically. The deployment workflow will run after changes are pushed to `main`.
